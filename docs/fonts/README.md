# Bundled Jumbotron fonts (OFL)

SportsDash ships three SIL Open Font License faces. No runtime font fetch.

| Face | File | Role |
|---|---|---|
| Bebas Neue Regular | `SportsDash/Fonts/BebasNeue-Regular.ttf` | Display (titles, abbr, filters, settings labels) |
| Orbitron Black 900 | `SportsDash/Fonts/Orbitron-Black.ttf` | LED digits and status |
| Space Mono 400 / 700 | `SportsDash/Fonts/SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf` | Body / captions |

Licenses (verbatim OFL 1.1) live next to the files and in this folder:

- `OFL-BebasNeue.txt` — The Bebas Neue Project Authors
- `OFL-Orbitron.txt` — The Orbitron Project Authors
- `OFL-SpaceMono.txt` — The Space Mono Project Authors

Android copies: `android/app/src/main/res/font/{bebas_neue,orbitron_black,space_mono,space_mono_bold}.ttf`.
